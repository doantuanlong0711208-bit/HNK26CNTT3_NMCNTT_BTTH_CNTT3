# GreenField – Đặt sân bóng mini
Website giúp các bóng thủ dễ dàng **đặt sân** *bóng đá mini* nhanh ở quanh khu vực đang đứng.
| Thư mục | Nội dung |
| --- | --- |
| docs | tài liệu bàn giao |
| data | Bảng tính đặt sân |
| logs | Log truy cập website |

Câu lệnh liệt kê toàn bộ nội dung dự án.
```Powershell
ls -Force
```
